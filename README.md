# Music Party catalog delivery

Public music metadata, numeric analysis and the scheduled updater only. Roblox gameplay source remains in the private game repository. No raw audio is published or committed.

GitHub Actions refreshes the official ranking daily at 18:17 UTC (03:17 JST), on policy/updater changes, and on manual dispatch. The Human-maintained selection-policy.json sets chartLimit=100 as the search ceiling and chartTarget=20 as the number of successfully analyzed chart songs to admit. It walks rank order, skips NG and manual duplicates, replaces unavailable/invalid audio from lower ranks, and stops after 20 successes. Manual registrations are processed separately. If 100 ranks cannot supply 20 chart songs, no new manifest/history is committed or deployed; the previous site remains intact. Official public audio is temporary, hashed and checked against numeric-analysis cache before activation.

The game checks for completed generations every 6 hours and adopts them only between rounds. It validates metadata and every profile before switching. No Lua source or executable payload is fetched. Unknown formats, invalid profiles, inaccessible audio and empty pools fail or exclude with a report. A previous in-memory catalog and the bundled catalog remain available if delivery fails.

The updater uses Python 3.11, NumPy/librosa and ffmpeg/ffprobe. Long audio is analyzed only through the first 300 seconds; the full duration remains in metadata. Profiles are immutable by SHA-256 filename. Current and two prior generations are retained in each deployment. Source metadata: https://apis.roblox.com/music-discovery/v1/top-songs?pageToken=0&limit=100 . health.json reports chartTarget, chartEligible and manualEligible separately.

The chart target starts at 20. As Human registrations grow, raise it explicitly to 30 after Human decides the timing. Manual count never changes the target automatically; there is no invented count threshold. Chart candidates remain bounded at 40 plus at most 40 independent manual entries. Legacy manifests without chartTarget remain readable by the game; an older generation or bundled fallback can temporarily contain fewer than the new target.

Mode scope: PARTY and BATTLE randomly select only the current 20 chart songs plus active Human registrations from manifest.json. Past chart songs remain in the permanent library for SOLO selection, favorites and records; they are not added back to the PARTY/BATTLE shuffle bag. Current NG rules apply in every mode. A future chartTarget of 30 changes the current chart quota, not archive retention.

The permanent song library is separate from that short HOT history. `archive/registry.json` and `archive/profiles/` are committed data, independent of Actions cache. `library.json` publishes up to 200 metadata rows per immutable page and keeps past songs and profiles after they leave HOT. Current policy still controls playback. After successful Pages deployment, the record job validates and commits the complete archive without deleting old songs. Tool deployments seed it once and never overwrite the workflow-owned archive. Favorites and player scores are private Roblox data and are never included here. The archive recorder uses only the Python standard library.

The private repository's catalog-service directory is the updater source. Copy only its contents here. Never copy .git, Studio files, raw recordings/audio, credentials or game Luau source. Policy updates must update the private canonical list and this public mirror together. Successful deployments record last-refresh.json on the default branch, keeping real catalog update activity visible. GitHub schedules may be delayed; workflow failures remain visible in Actions and the last successful health.json.

Human registrations in manual-tracks.json join the chart even outside the chart search window (up to 40 manual tracks). All share NG filtering, real PCM/beat analysis, and a unique asset slot; manual metadata takes precedence over a chart duplicate. Registered title/artist/art are verified metadata snapshots, so daily jobs do not repeatedly call the rate-limited economy API. ID-only entries resolve there with bounded transient retry. Creator.Name is the uploader, not a guaranteed composer. A Human artist override can supply a verified composer. Art 0 uses the game’s note fallback. Raw audio is still downloaded/hashed and decoded before admission. HTTP 429/temporary 5xx retry at most four attempts; persistent failure preserves the prior generation.
